## 自动化验证

运行命令：

```powershell
node --test --test-isolation=none tests/*.test.mjs
```

测试覆盖 CSV 引号与异常数据、超限点判定、公式安全导出、优先级调度、同一物理通道互斥、共享仪器锁和独立资源并行、暂停恢复、取消释放锁、设备断开、并发调整、SQLite 持久化、历史阈值、36 通道执行、采集线程异常、服务重启恢复、HTTP 输入与路径校验、SSE 更新、中文请求跨 TCP 分块等。

最终结果：**28 项测试全部通过，0 失败**。额外回归测试覆盖扫描中心值合格但频点超限的判定、观测范围、未选指标不生成曲线，以及采集线程与演示报告的一致性。

所有测试使用内存或临时数据库，和用户运行时的数据分开。

## 交付限制

当前使用模拟采集与阈值规则。设备地址仅用于记录联调参数，未建立真实仪器连接。YOLOv5 权重、训练集、设备协议和校准资料尚未提供，真实硬件控制与机器学习评估需以这些资料继续集成。PPT 中的错误率和效率提升目标没有通过本项目的软件仿真验证。
